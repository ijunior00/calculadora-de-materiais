1. Introduction
1.1 What is the BRMP?
The Blade Repair Materials Planner (BRMP) is an internal web application developed by the Brazil Blades Service Team to streamline the planning and material estimation process for wind turbine blade shell laminate repairs.

Before BRMP, technicians manually calculated fabric quantities, chemical amounts, and consumable counts using Excel spreadsheets — a time-consuming and error-prone process. BRMP automates all these calculations from a simple 4-step data input flow, producing a complete Bill of Materials (BOM) in seconds.
1.2 What does it cover?
  • Fabrics (BIAX, UD, TRIAX, CORE, BALSA, SPL, CFM)
  • Chemicals (epoxy resins, adhesives, top coat, alcohol, cleaning cloth)
  • Consumable Tools (grinding discs, putty knives, spatulas)
  • Consumables (peel ply, release film, infusion mesh, vacuum tape, breather)
  • Tools (vacuum pump, scales, mixing machine)
  • PPE (dust loops, gloves, suit, cream)
1.3 Limitations
BRMP is designed exclusively for general shell laminate repairs. LPS, spar cap, shear web, root, insert, or engineering sign-off repairs are NOT covered.

1.5 How to Launch
  1. 1Navigate to the application folder.
  2. 2Double-click INICIAR_CALCULADORA.bat. A CMD window opens.
  3. 3After ~3 s your browser opens at http://localhost:8010.
  4. 4Click the blue "Damage Data" button to begin.
Prerequisites: Python 3.10+ (Anaconda3 recommended). First run installs packages automatically (internet required).
Keep the CMD server window open while using the tool. Closing it stops the server.
1.6 Navigation Bar
The dark-blue top bar shows 4 numbered steps: Damage Data → Layer Data → Repair Steps → Results. A Reset button (top-right) clears everything. The v1.0 badge confirms the running version.

3. Step 2 — Layer Data Input
3.1 What are Layers?
Layers represent the repair laminating stack — the sequence of fabric plies applied during repair, from innermost (closest to blade surface) to outermost. This stack drives fabric quantity calculations.
3.2 The Layer Table
ColumnDescription
#Layer number (order in stack)
Layer NameFree text — repair drawing layer ID (e.g. "270A", "150B")
Material TypeDropdown filtered by blade model (BIAX 1000, UD 1200, TRIAX, CORE, SPL, BALSA, CFM)
GSM AUTOAuto-filled from material selection
Scarffing OrderOptional grinding/scarffing reference
Move / DeleteReorder or remove layers
SPL, CORE, BALSA and CFM must be explicitly added as layers if the repair requires them.
3.3 Material Type Dropdown
Only shows fabrics valid for the confirmed blade model, based on the REV05 Blades_Fabrics matrix. e.g. V150 shows BIAX 600/1000/1200 (HM catalog) while V82 shows BIAX 936.
3.4 Layer Order Matters
The sequence determines cumulative spanwise and chordwise overlap accumulation. Enter from Layer 1 (innermost/smallest) to last layer (outermost/largest scarffing). Use arrows to reorder.
3.5 Confirming Layers
Once configured, click "CONFIRM LAYERS". A green lock banner appears. To modify: click "UNLOCK".
After locking layers, click "Next: Repair Steps" to proceed to Step 3.

6. PDF Report — Generation & Location
6.1 Generating the Report
At the bottom of Step 4, click "Generate PDF Report". The server creates the PDF and triggers a browser download. A copy is also saved server-side.
6.2 Output Folder
All PDFs are saved in: BOM_Reports_Generated\
Located in the same directory as INICIAR_CALCULADORA.bat.
6.3 Filename Logic
BOM_Report_[BladeModel]_[SO_or_CIR]_[YYYYMMDD].pdf
PartSourceExample
BladeModelFrom Step 1V150
SO_or_CIRSO field (fallback: CIR)SO-2025-001
YYYYMMDDGeneration date20260428
If SO and CIR are blank, filename shows UNKNOWN. Always fill at least the SO.
6.4 PDF Content
  • Header: "VESTAS | BRMP" + date + "Confidential"
  • Info block: turbine, zone, SN, SO, CIR, dimensions, days, description
  • BOM tables: one section per category with SAP, Description, QTY, UNIT
  • Footer: page number + timestamp + "Vestas Internal Use"

7. Troubleshooting & Best Practices
Common Issues
ProblemSolution
Error generating PDFServer not running. Re-run INICIAR_CALCULADORA.bat and wait for CMD startup message.
PDF shows UNKNOWNSO and CIR fields were blank in Step 1. Go back, fill SO, regenerate.
Blank page / cannot connectServer needs ~3s to start. Refresh (F5). Check CMD for Python errors.
Wrong materials in dropdownBlade model not confirmed. Go to Step 1 and click CONFIRM.
Need to change blade modelClick EDIT in the confirmation banner. Note: layers are reset.
Vacuum count wrongVacuum = HLU + Infusion (auto). Adjust those values in Step 3.
Fresh start neededClick Reset in the top-right nav bar to clear everything.
Best Practices
  • Always confirm blade model before entering coordinates
  • Fill SO or CIR for meaningful PDF filenames
  • Enter layers innermost → outermost (drives overlap calc)
  • Hover all (i) icons in Step 3 before first use
  • Root region: select "Root" for correct CORE kit SAP
  • Single repair estimate only — multiply manually for batch
  • Keep the CMD server window open at all times
Quick Reference Flow
  1. 1Launch BAT → browser opens
  2. 2Click "Damage Data" on Welcome Page
  3. 3Step 1: select + confirm model → fill coords → Next
  4. 4Step 2: add layers → confirm → Next
  5. 5Step 3: set repair steps + blade info → Calculate BOM
  6. 6Step 4: review tabs → Generate PDF Report
  7. 7Find PDF in BOM_Reports_Generated\
